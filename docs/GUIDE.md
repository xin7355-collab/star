# 使用說明

## 安裝到 iPhone 主畫面

用 Safari 打開 https://xin7355-collab.github.io/star/ →「分享」→「加入主畫面」。之後像 App 一樣全螢幕開啟，
沒有網路也能用（第一次開啟要有網路）。

有新版時會自動更新：打開 App 或切回 App 時檢查版本，發現新版會提示「發現新版本，更新中…」並重新載入一次。

## 五個分頁

| 分頁 | 內容 |
|---|---|
| 我的 | 國曆或農曆生日（可選閏月、民國或西元）→ 星盤、農曆生日與生肖。可存多人（家人朋友，最多 50 人），用上方選單切換正在看的人；新增家人不會搶走「我」。下面有查詢紀錄、備份與隱私。 |
| 運勢 | 今日／明日／本週／本月／今年的星座運勢（今年看 12 個月走勢），四項分數與「為什麼是這個分數」。農民曆卡：宜忌、沖煞、彭祖百忌、吉神方位、節氣節日，可前後翻日；沖到你的生肖會提醒。 |
| 命理 | 八字（四柱、十神、藏干、納音、五行、大運）、流年（含犯太歲）、紫微斗數（12 宮，點宮位看細節）、瑪雅曆（可比對兩人）、生命靈數（九宮格）、稱骨。結果可「存到紀錄」或存成圖卡。 |
| 配對 | 快速（只選星座）或精準（從名單選人，或另外輸入生日）；最多 5 人，多人分數取兩兩平均。 |
| 塔羅 | 單張／三張／五張牌陣，手機加密亂數、不放回抽牌。問題不會儲存。 |

每個結果都能「存成圖卡」，iPhone 會跳出分享面板，可存相簿或傳 LINE、IG。

## 計算方式

- **星座用太陽實際黃經判斷**，不用寫死的日期表；生日在交界又沒填時間，會顯示確切換座時刻。
- **出生時間未知不假設午夜**：改列當天各行星可能的星座；紫微需要出生時間，沒填會提示到「我的」補上。
- **時區含台灣歷史日光節約時間**（1945–1979 年夏季 UTC+9）；遇到被跳過或重複的時刻會請你確認。
- **八字**：年柱、月柱以節氣交接時刻（台灣時間）判斷；日柱、時柱用當地標準時間（自動扣掉日光節約時間）。
  命理頁「設定」可選子時換日（23 點換日為預設，或 0 點換日）與真太陽時（依出生地經度與均時差校正）。
- **犯太歲**用「民俗生肖」：以農曆正月初一換年，不是立春。
- **運勢分數**是占星娛樂規則（依當天行星與你太陽星座的相位加減分），規則公開、同樣輸入得到同樣結果，**不是科學預測**。
- 命理與星座內容僅供娛樂參考。

驗算結果見 [DECISIONS.md](DECISIONS.md)。

## 隱私

- 名單、生日、查詢紀錄只存在這支手機（瀏覽器本機儲存），**不會上傳**。App 只向自己的網站下載程式檔，
  自動測試會檢查沒有送出任何資料、網址不含生日。有設定 AI 短評時，只另外向自己的 Worker 取「這一期」的短評，
  請求裡沒有任何個人資料。
- 「我的」→「備份與隱私」：
  - **匯出備份檔**：換手機或清除前先存一份（存到「檔案」或雲端硬碟）。
  - **匯入備份檔**：可選「合併（保留手機上的）」或「全部取代」；格式不對的資料會略過並告訴你幾筆。
  - **清除這支手機上的全部資料**。
- 瀏覽器在空間不足或很久沒開時可能清掉網站資料，建議加入主畫面並定期匯出備份。
- 查詢紀錄最多存 300 筆，畫面列最近 50 筆；全部紀錄都在匯出的備份檔裡。
